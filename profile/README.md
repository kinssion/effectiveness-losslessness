# Public research profile

`YiWang_Public_Research_CV.pdf` is Yi Wang's public research CV.  It is
included as an author-profile companion and is not part of the paper's
scientific evidence, model inputs, or reproducibility claims.

The PDF intentionally includes the author's public institutional contact
address and public profile links.  Its two pages and metadata were reviewed
before inclusion; binary PDF content is outside the repository scanner's
UTF-8 text-file pass and is instead covered by the release hash inventory.

The layout is adapted from
[adongwanai/LLM-Resume-Template](https://github.com/adongwanai/LLM-Resume-Template)
under CC BY 4.0.  Attribution is also embedded in the PDF.
